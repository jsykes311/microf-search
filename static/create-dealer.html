Creates the full record set a normal warehouse/dealer.microf.com push would create — Account, Contact(s), and SLP — for one-off cases where that pipeline is down or a dealer needs to be entered by hand.

  • Fill in the required fields (marked *), then click Check for Conflicts.
  • If a dealer_id already has an SLP, creation is blocked — that's a real duplicate, not a false alarm. Matching account names or contact emails are shown as warnings, not blockers, since they're common (e.g. re-enrolling under a new channel).
  • Leave Assigned BDR blank to auto-apply the standard rule: House for Microf Direct, Partner for every other channel.
  • If Business Manager is the same person as Owner, leave that box checked — only one contact gets created.
  • Every dealer created here gets a note on the Account and a tag on the Contact (default Manually-Created-ETL-Down) so these are easy to find as a group and reconcile if the source system later creates a duplicate.
